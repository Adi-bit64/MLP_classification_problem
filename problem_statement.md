# Dataset Description
The Mushroom Dataset is a classic machine learning classification benchmark used to predict whether a wild mushroom is Edible (e) or Poisonous (p) based on its physical traits. Key Stats


Size: 8,124 samples.

Features: 24 features (Cap shape, Gill color, Odor, Habitat, etc.).

Target: Binary classification (Edible vs. Poisonous).

Data Type: Features are a mix of numbers, characters and strings.
